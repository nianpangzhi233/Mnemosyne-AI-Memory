# Code of Conduct

Mnemosyne follows a simple rule: be direct, technical, and respectful.

## Expected Behavior

- Discuss ideas with evidence.
- Keep issues reproducible and focused.
- Respect privacy when sharing logs, memories, configs, or screenshots.
- Assume contributors are trying to improve the project.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing someone else's private data, API keys, memory databases, or logs.
- Spamming issues or pull requests.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this policy.
